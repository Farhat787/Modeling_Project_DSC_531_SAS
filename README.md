# DSC 531 - Regression Modeling Project
This project uses IPEDS (Integrated Postsecondary Education Data System) data 
to build regression models predicting baccalaureate graduation rates across 
U.S. postsecondary institutions. The analysis explores both continuous prediction 
of graduation rates using linear regression and binary classification of whether 
an institution falls above or below the median graduation rate using logistic 
regression. All models are limited to institutions with an incoming cohort of 
at least 200 students.

## Data Source
IPEDS datasets: Graduation, Graduation Extended, Characteristics, 
Tuition and Costs, Salaries
